# PriceTracker

Отслеживание цен товаров с Яндекс.Маркета. Вставляете ссылку на товар —
сервис вытаскивает название и цену, сохраняет и показывает историю
изменений.

Backend на FastAPI, база — SQLite, простой веб-интерфейс на чистом
JavaScript. Всё запускается через Docker.

## Запуск

Нужен только Docker.

```bash
cp .env.example .env
docker compose up -d --build
```

Приложение поднимется на <http://localhost:8001>. База лежит в отдельном
томе, при пересборке и перезапуске не теряется.

Остановить: `docker compose down`. С удалением базы: `docker compose down -v`.

## Запуск без Docker

Нужен Python 3.11.

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8001
```

По умолчанию база — файл `data/pricetracker.db`, создаётся сам при первом
запуске.

## API

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/search?query=<url>` | Разобрать товар по ссылке Яндекс.Маркета |
| POST | `/api/track` | Добавить товар в отслеживание |
| GET | `/api/tracked-products` | Список отслеживаемых товаров |
| GET | `/api/stats/{id}` | История и статистика цены |

## Настройки

Задаются в `.env` (пример — в `.env.example`):

- `APP_PORT` — порт приложения, по умолчанию 8001
- `DATABASE_URL` — строка подключения к базе; по умолчанию локальный
  SQLite. Внешний PostgreSQL, если понадобится, указывается здесь — в
  коде никаких паролей нет.

## Структура

```
app/
  main.py             маршруты FastAPI
  database.py         подключение к базе
  models.py           таблицы: товары и история цен
  schemas.py          схемы запросов и ответов
  crud.py             операции с базой
  yamarket_parser.py  разбор страницы Яндекс.Маркета
  static/             веб-интерфейс
```

## Про парсер

Цена и название вытаскиваются из HTML страницы регулярными выражениями.
Яндекс периодически меняет вёрстку, поэтому парсер иногда может
переставать находить цену — это ожидаемо и лечится обновлением шаблонов
в `yamarket_parser.py`.
